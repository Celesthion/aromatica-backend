# Акции-подарки

Правило `gift_rule` — это условия, набор подарка и кратность. Настраивается в
админке. Касса показывает подходящие акции в чеке, а выдавать ли подарок,
решает продавец.

## Условия

Типы `gift_condition`:

- `SUM` — платная сумма чека не меньше `min_sum_minor`
- `KIND` — в чеке есть товар формы `kind`, можно с минимальным объёмом
  `min_volume_ml` (у наливных — налитые мл строки, у штучных — объём товара)
- `PRODUCT` — в чеке есть конкретный товар

Условия собраны в группы: внутри группы «И», между группами «ИЛИ». Подарочные
строки не учитываются. Пороги сравниваются с суммой до скидки на чек.

## Кратность

За выполненное условие — один подарок. `step_minor` даёт ещё по одному за
каждые N сверх наибольшего выполненного SUM-порога (от наименьшего вышло бы
слишком много). `max_gifts` — потолок на чек.

## Набор

Набор состоит из `gift_item`: конкретный товар с количеством или «любой товар
формы X», который продавец выберет на кассе. Строки одного выданного набора
связаны `giftGroupId`: считаются одним подарком, удаляются из чека вместе,
стоят ноль, а товар списывается по себестоимости.

Если после выдачи корзину урезали или правило выключили, подарков может стать
больше положенного. Тогда касса не даёт оплатить, пока лишний набор не уберут.

В подарках участвуют только формы с флагом `gift_eligible`.

На фронте то же самое считает `src/pages/pos/lib/gifts.ts` (фронт-репа), по
образцу `GiftRuleService`. Юнит-тесты есть с обеих сторон.
